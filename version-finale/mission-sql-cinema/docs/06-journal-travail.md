# Journal de travail

Ce document est un modèle. Il ne constitue pas un historique des heures déjà effectuées. Les collaborateurs doivent compléter et vérifier chaque entrée à partir de leurs traces réelles.

## Consignes

- Ajouter une ligne environ toutes les trente minutes de travail.
- Séparer les tâches des deux collaborateurs.
- Noter les erreurs et essais infructueux, pas uniquement les réussites.
- Ne pas inventer de dates, d'heures, de recherches ou de résultats.
- Faire vérifier les entrées historiques par les personnes concernées.
- Indiquer les temps prévus séparément des temps réellement réalisés.

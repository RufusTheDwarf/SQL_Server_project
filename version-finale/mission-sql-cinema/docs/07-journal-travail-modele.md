# Journal de travail

Ce document est un modèle de saisie. Il ne constitue pas un historique déjà réalisé.

## Consigne

Créer environ une entrée par demi-heure de travail. Noter les essais réussis, les erreurs, les recherches, les corrections et les résultats observables.

Ne pas reconstituer un historique de mémoire sans preuve. Si une date, une durée ou le nom d'un collaborateur est inconnu, l'indiquer comme inconnu. Les heures individuelles ne doivent être inscrites que si elles ont été relevées.

Pour chaque entrée, préciser :
- Date et plage horaire.
- Durée réellement consacrée.
- Collaborateur concerné.
- Tâche effectuée.
- Recherche ou source consultée.
- Résultat vérifiable, par exemple un commit, un test ou un fichier.
- Difficulté rencontrée et suite prévue.

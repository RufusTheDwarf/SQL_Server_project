# Checklist de migration

## Avant le déplacement

- [ ] Confirmer le scénario avec l'enseignant.
- [ ] Confirmer les versions de Windows, SQL Server, Python et ODBC sur le PC cible.
- [ ] Exécuter les scripts SQL et vérifier dix millions de réservations.
- [ ] Mesurer la durée de génération et l'espace disque.
- [ ] Installer les dépendances Python.
- [ ] Exécuter les tests unitaires.
- [ ] Chronométrer une partie complète.
- [ ] Préparer une sauvegarde de la base et vérifier la procédure de restauration.
- [ ] Préparer une activité de secours si SQL Server tombe en panne.

## Sur le PC cible

- [ ] Vérifier l'instance SQL Server et les droits d'accès.
- [ ] Configurer les variables d'environnement.
- [ ] Lancer l'application depuis le dossier transféré.
- [ ] Vérifier que les résultats viennent de SQL Server et qu'aucun bandeau de simulation n'est affiché.
- [ ] Tester les trois défis.
- [ ] Tester la remise à zéro de la partie.
- [ ] Tester clavier et souris.
- [ ] Vérifier la lisibilité sur l'écran utilisé.
- [ ] Vérifier que le navigateur ouvre bien l'adresse locale.
- [ ] Noter les problèmes rencontrés et les solutions.

## Secours

Si SQL Server n'est pas disponible, ne présenter le mode simulation que comme simulation. Prévenir l'enseignant ou l'animateur responsable et utiliser une activité de secours approuvée.
